# IIS Node-hosting components: availability and support evidence

Research snapshot: 2026-10-13. This note evaluates Microsoft's current published availability and support/lifecycle statements for HttpPlatformHandler, Application Request Routing (ARR), and URL Rewrite. It separates product age from explicit deprecation or support statements. It does not establish compatibility with Windows Server 2025.

## Findings

| Component | Current Microsoft-published item | Published compatibility / maintenance evidence | Windows Server 2025 conclusion |

## What the evidence does and does not say

- The IIS download pages are live and link direct Microsoft installer files as of this snapshot. ARR and URL Rewrite can therefore still be obtained without Web Platform Installer (WebPI).
- Microsoft's IIS downloads site labels these items as Microsoft Supported Downloads. The category says: “Microsoft downloads are fully supported with future updates, bug fixes and customer support.” ARR also has a Microsoft Learn statement that support is provided by Microsoft Help and Support. These are meaningful support signals, but they do not state the exact Windows Server versions covered or guarantee that a newer module release will be produced.
- Microsoft explicitly ended WebPI product support on 2022-07-01, locked catalog updates then, and removed its feed and installers on 2022-12-31. This is the lifecycle of the installation/catalog tool, not a deprecation notice for ARR, Rewrite, or HPH; their independent direct download pages remain available.
- The component pages list IIS only through version 10. Microsoft's Windows Server 2025 documentation identifies Windows Server 2025 as the current LTSC release and gives OS lifecycle dates, while the Windows Server removed/deprecated-features page does not list ARR, URL Rewrite, or HttpPlatformHandler in its reviewed content. Neither fact supplies an add-on compatibility statement for those modules on Server 2025.
- Several version/release records are old: ARR 3.0 update from 2015, HPH v1.2 listing from 2015, and URL Rewrite 2.1 from 2017. That is evidence of a long unchanged release line. It is not itself evidence that Microsoft has deprecated these modules or withdrawn support.
- The official IIS lifecycle page states that IIS follows the Windows OS lifecycle. That statement applies to the IIS component; it should not be extended to separately downloaded modules without their own stated support scope.
